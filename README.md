## 💻 3. Cấu Hình Máy Tính Phù Hợp (Chạy Được Ngay Trên 01 Laptop Windows Bình Thường)

Hệ thống hỗ trợ **02 chế độ vận hành linh hoạt**:

### Chế độ A — Chạy trực tiếp trên 01 máy tính Windows duy nhất (`"mode": "local"` — 95% khách hàng sử dụng)
* **Hệ điều hành**: Windows 10 hoặc Windows 11 (64-bit).
* **CPU & RAM**: Intel Core i3 / AMD Ryzen 3 trở lên, RAM tối thiểu **8 GB** (khuyên dùng 16 GB nếu mở kèm Cursor / Antigravity).
* **Màn hình**: Độ phân giải chuẩn Full HD **`1920 x 1080`**, tỷ lệ thu phóng (**Scale & Layout = `100%`**).
* **Phần mềm sẵn có**: Google Chrome (đã đăng nhập sẵn tài khoản `muasamcong.mof.gov.vn` tại `Profile 1`), phần mềm `eGP-Agent` của Bộ KH&ĐT, Python 3.10+ và cắm sẵn USB Token chữ ký số.
* **Ưu điểm**: **Không cần mạng LAN, không cần cấu hình WinRM**, chạy trực tiếp 1-Shot ngay trên máy!

### Chế độ B — Dùng MacBook / Linux điều khiển máy trạm Windows cắm USB Token qua mạng LAN (`"mode": "winrm"`)
* Dành cho Giám đốc dùng MacBook muốn ra lệnh cho AI đẩy hồ sơ sang máy PC Windows văn phòng cắm sẵn USB Token để ký số từ xa qua giao thức `WinRM` (`port 5985`).

2. **Không can thiệp hệ thống & Không vượt rào bảo mật**: Phần mềm **tuyệt đối không** can thiệp trái phép vào cơ sở dữ liệu của Hệ thống Mạng đấu thầu quốc gia, **không** giải/vượt CAPTCHA tự động (người dùng tự đăng nhập hợp pháp trên Chrome Profile của mình), và **không** gửi truy vấn tần suất cao gây ảnh hưởng hạ tầng.
3. **Chống Thông Thầu (1 License = 1 Mã Số Thuế = 1 Máy Trạm)**: Mỗi giấy phép `license.lic` được khóa cứng bằng mật mã bất đối xứng **RSA-2048** vào **đúng 01 Mã số thuế (`MST`) trên USB Token** và **01 Mã phần cứng máy tính (`HWID`)**, ngăn chặn triệt để việc sử dụng 1 máy trạm nộp hồ sơ cho nhiều pháp nhân khác nhau.

## 🛠️ 5. Hướng Dẫn Cài Đặt & Sử Dụng Trong 3 Phút

```bash
git clone https://github.com/vanthangqtbv-cpu/muasamcong-autopilot-sdk.git
cd muasamcong-autopilot-sdk
pip install -r requirements.txt
```

### Chọn 1 trong 6 bộ cấu hình ngành nghề có sẵn (`presets/`):
* `presets/01_thiet_bi_y_te_duoc_pham.json` — Thiết bị Y tế, Hóa chất xét nghiệm & Dược phẩm
* `presets/02_xay_dung_co_dien_pccc.json` — Xây lắp, Cải tạo sửa chữa, Cơ điện M&E & PCCC
* `presets/03_ve_sinh_cong_nghiep_canh_quan.json` — Dịch vụ Vệ sinh công nghiệp & Cảnh quan
* `presets/04_cntt_phan_mem_van_phong.json` — CNTT, Phần mềm, Máy tính & Thiết bị văn phòng
* `presets/05_kiem_soat_dich_hai_diet_con_trung.json` — Dịch vụ Kiểm soát dịch hại, Diệt côn trùng & Khử khuẩn
* `presets/06_suat_an_thuc_pham_bao_ve.json` — Cung cấp Suất ăn công nghiệp, Thực phẩm & Dịch vụ Bảo vệ

```bash
cp presets/01_thiet_bi_y_te_duoc_pham.json config/company_profile.json
```

### Các lệnh vận hành chính:
```bash
# 1. Xem Mã Phần Cứng (HWID) & số lượt miễn phí còn lại:
python3 bin/ebid_autopilot.py status --profile config/company_profile.json

# 2. Săn gói thầu & Yêu cầu báo giá mới theo từ khóa ngành nghề:
python3 bin/ebid_autopilot.py hunt --profile config/company_profile.json

# 3. Kiểm tra Pre-Flight máy Windows & USB Token:
python3 bin/ebid_autopilot.py preflight --profile config/company_profile.json

# 4. Nộp Báo Giá & Ký Số USB Token 1-Shot (45 giây):
python3 bin/ebid_autopilot.py submit \
  --profile config/company_profile.json \
  --pkg-code "RQ2600100001" \
  --unit-prices "26000000,8500000,15500000" \
  --bundle-file "C:\Users\Public\00_Ho_So_De_Xuat_Tong_Hop_Full.zip" \
  --doc-name "Ho so bao gia va nang luc du thau RQ2600100001" \
  --proof "./Minh_Chung_Nop_Thau_RQ2600100001.png"
```
